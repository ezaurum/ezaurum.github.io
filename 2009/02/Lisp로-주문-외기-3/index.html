엄청나게 좋은 Lisp컴파일러가 많이 있지만, 이 강좌를 들으며 쓰기 가장 쉬운 것은 Franz의 Allegro Common Lisp, 매우 강력한 상업용 Lisp입니다. Franz, Inc. 는 친절하게도 텔넷환경을 통해서 사용할 수 있도록 해 주었지요. 여기에 있으니까 컴퓨터에 아무 것도 깔 필요는 없어요. 그냥 이 링크를 클릭하면 원하는 모든 것을 제공해주는 텔넷 화면이 뜰 겁니다! [caption id=“attachment_382” align=“alignnone” width=“400” caption=“telnet화면”]/caption [caption id=“attachment_381” align=“alignnone” width=“500” caption=“reset하고 싶을 때는 :res”][/caption] Allegro Common Lisp를 쓰고 있다면, Lisp 명령줄에서 다음을 실행해 보세요. (setf tpl:print-length nil) 일단 브라우저에서 이걸 복사해서 텔넷 창에서 오른쪽 클릭을 하고, 붙여넣기를 선택합니다. 이 줄에 대해서 너무 신경쓸 필요는 없어요. 이건 그냥 알레그로가 우리의 텍스트 게임에서 출력되는 문장을 썰어대는 걸 방지하는 것 뿐이에요.
