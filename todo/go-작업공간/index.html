Go 는 작업 공간을 GOPATH 라는 환경변수에 지정한다. 다른 언어에서는 각 프로젝트마다 독립적으로 쓰고 있지만, Go 에서는 한 군데에 모아서 쓴다 C:\workspace\go 또는 ~/workspace/go 를 작업공간으로 쓰기로 했다면, 내부에

go |– bin | 실행 파일이 존재한다. Go 언어에서 사용하는 util 등이 여기 저장되고, 추가로 설치도 가능하다. | |- pkg | 참조되는 외부 패키지들이 저장된다. | |- src 실제 소스가 들어가는 위치

src 내부에는 github.com bitbucket.org 형태로 저장된다.
