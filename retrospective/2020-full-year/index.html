  1. 5000커밋 달성

  3. 학자금 융자 모두 상환
  4. 집에 가전제품을 많이 샀다

  7. 목표로 삼았던 콘크리트 매쓰매틱스도 실패
  8. Go 스터디 모임 하나 진행
  9. Node JS 프로젝트 하나 진행
  10. 오랜만에 Java + Spring + MyBatis 프로젝트 진행
  11. 손 댄 프로젝트 우상향 중

감상

  1. 나쁘지 않다. 어제보다 나은 내일을 기대하고 있다
  2. 실력이 좀 늘었다는 느낌
  3. 우상향 하는 프로젝트는 참 기분이 좋다

교훈

  1. 규칙적인 생활이 중요하다 - 말 뿐만이 아니라 실행이
  2. 충분한 수면과 운동이 필요하다
