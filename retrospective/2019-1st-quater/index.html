2019년 1사분기 회고

2019년 5월 12일 회고

한 일

  1. 1월에서 2월까지는 큰 회사에서 내부 레거시 시스템을 정리하는 팀 외주가 들어와서 팀 구성을 위해 돌아다님

    1. 별로 성과 없었음

  2. 2월부터 출퇴근을 하기 시작함

    1. 외부 API 연동
    2. R&D 이것저것 - micronaut, CI/CD

  3. 뽑기를 만들면서 순열을 이해했다.

  4. CodeJam 도전

  5. 리디셀렉트를 쓰면서 좀 책을 더 보게 되었다

  6. 출퇴근을 하니까 규칙적인 생활을 했다

  7. 드디어 도커로 배포를 시작했다.

감상

  1. 소설을 다시 써 보기로 했다.
  2. 카지노 게임 만들 때 순열이 이해가 되었으면 좋았을 텐데
  3. CodeJam 은 더 어려워졌다.
  4. 금전적 여유가 생기니 마음에도 여유가 생겼다.
  5. 확실히 전보다 더 많은 일을 할 수 있게 되었다.
  6. 잘 하는 사람들이 보이니 자극이 되어 더 많은 일을 한다.

교훈

  1. 면접을 어떻게 볼 것인가 - 남의 실력을 어떻게 판별할 것인가 하는 기준을 생각해야 함 - 반대로 내 실력은 어떻게 드러낼 것인가
  2. 조직 내에서의 역할을 명확히 해야 함
  3. 연습이 중요. 좀 더 하자.
  4. 규칙적인 생활과 지적 자극이 중요. 잘 하는 사람들 사이에 있자.
