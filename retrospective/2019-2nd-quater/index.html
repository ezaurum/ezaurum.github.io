2019년 2사분기 회고

2019년 7월 1일 회고

한 일

  • 첫 일본여행 - 후쿠오카 4박5
  • 컴 업글 - AMD로 돌아감
  • 운동시작 - 6.10 부터
  • 유니티 앱 개발 - 시작만 함 AR전화 서비스 구조개선
  • 네이버에서 AWS로 운영서버 이전
  • 도커로 빌드, 배포
  • 오래 묵은 DB 트랙잭션 중 예외처리 중 rollback 처리가 되지 않은 버그 수정.
  • 코오롱 리뷰 - 크레마API 연동
  • 스택 드라이버 세팅 공부
  • 웹에서 이어올리기 기능 구현
  • 람다를 해 봄
  • 여러 CI/CD 서비스 조사
  • 고시원 생활 시작 - 3개 회사 일이라 출퇴근 시간을 줄이기 위해
  • 회사 정기 소모비용 발생 - 서버/고시원 비용
  • 대출금 1건 변제 완료
  • 빠찡꼬 해봄
  • 목표 연수입 달성

감상

  • 큰 통신사도 역시 구리다.
  • 일본은 미묘하게 비싸다. 강제로 비싸고 퀄 좋은 것만 먹게 된다.
  • AWS는 역시 좋다. 기능이 많고 실제론 더 싸게 운영가능
  • 역시 일은 지르면 된다.
  • Docker 역시 좋다.
  • 세상에 좋은 서비스는 많다. 돈만 내면 돼.
  • 빠찡꼬는 괜찮다. 슬롯과는 다른 재미. 하지만 시끄러워.
  • 대출을 정리하는 건 기분이 좋다.
  • 돈 버니까 좋다.

교훈

  • 플랫폼 이전에는 1주를 잡자
  • 외부 API 연동은 항상 안 될 수 있다는 걸 염두에 두자.
  • 외부 API 연동하기 전에, 가능하면 내 쪽 프로세스를 먼저 정리하자
  • 항상 손절각을 재자
  • 급하다는 일은 가능하면 안 하는 게 좋다.
  • 자동화는 최대한 빨리 해야한다. Docker로 배포를 한 번 만들어놓고 스크립트로 실행하니 시간 많이 절약됨
  • 문서는 리모트일수록 도움이 된다.
  • 일본 여행중 급히 들어갈 만한 데는 빠찡꼬. WIFI도 무료. 충전도 된다. 하지만 시끄러우니 이어 플러그 필수.
  • 돈은 벌 수 있을 때 벌자.
  • 외부 서비스는 잘 찾아보고 쓰자. 괜히 고생.
