6월 마지막 주 정리

2012-07-01

버그 잡기 - 툴의 JS 구조 대충 파악, 그냥 잘못 된 것 찾아서 해결. 의미는 JS 짤 때 하지 말아야할 안티패턴 습득. 코드는 최대한 정리해야 함.

DB에 자료 직접 입력. 구조가 제대로 짜여지지 않은 상태지만, 대충 이전에 사용하던 것이 있어서 비슷하게 넣음. JIRA 미처리 이슈 정리 - 끝나 있었는데, 안 된 것으로 되어 있는 것도 많았음. JIRA나 여튼 그런 업무 관리 툴을 개인적으로도 쓰든지 해야 할 듯.

POI, google drive api 대충 조사. - 그냥 어떤정도인지만 알아봤음. 구글 쪽은 세세한 제어를 제공하지 않아서 파일을 받아온 다음 POI 등을 이용해서 컨버팅을 해 주어야 함. 구글 독스의 입력 기능을 사용하고 우리 서버에서 자료를 쓰려던 계획은 수정이 필요.

게임 기능 구현 - 계속 밀렸음.

중간에 버그 잡기라든가, 자잘한 일이 더 들어와서 좀 밀렸음.

완료율 6/11. 예상업무 다 못 끝낸 날이 나흘. 야근은 3일 함.

지각 하루.

한빛 번역 2건. 밤에 번역하느라 생활리듬 흐트러짐.

대충 나쁘지 않은 생활이지만, 역시 수요일 지나니까 몸에 효율이 떨어진다. 운동&규칙적 생활을 해야겠어. 한빛 번역도 이제 안 해야지. 내 실력이 부족한 탓이 크지만, 포인트 욕심을 내서 큰 기사를 맡으면 시간을 너무 잡아먹는다.

Backbone.js, CommonJS를 연습해야겠다. 좀 더 깔끔한 코드를 짜야지.
