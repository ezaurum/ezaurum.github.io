CLI로 클라우드 와치 로그 보기

2020년 3월 25일 레시피

목적

aws cli 로 cloudwatch 로그 보기 방법(윈도에서 awslogs가 안 먹을때)

  1. 로그 그룹 이름으로 로그 스트림들을 얻어온다 aws logs describe-log-streams --log-group-name /log/group/name
  2. 받아온 JSON에서 logStreamName 을 찾아 필요한 log stream name 을 알아낸다.
  3. 찾은 log stream 으로 로그를 얻어온다. aws logs get-log-events --output text --log-group-name /log/group/name --log-stream-name 2019/10/01/[$LATEST]hash
