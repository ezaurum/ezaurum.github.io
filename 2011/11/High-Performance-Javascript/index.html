High Performance Javascript

2011-11-05

쿡북이라고 붙지는 않았는데, 쿡북같다. 필요한 거 바로 찾을 수 있을 만 하게 되어 있고, 설명이 상세하게 되어있는데도, 책이 얇고 작아서 좋다. 꽉 들어찬 느낌이다. 당연히 자바스크립트를 빠르게 만드는 방법에 대해 설명이 되어 있고, 알던 방법은 더 상세히, 체계적으로 알 수 있어서 좋고, 모르던 방법은 모르던 걸 알아서 좋다. 지금 큰 사이트들이 사용하고 있는 방법들의 집대성이랄까. 여튼 만족스럽고, 표지의 부엉이가 똘똘해 보인다.
