에릭 마이어의 CSS 노하우

2011년 9월 11일 독서
에릭 마이어의 CSS 노하우 -
에릭 마이어 지음, 한선용 옮김/인사이트 진짜 순전히 저자 보고 샀다.

사고 나서 깨달았는데, 최초로 산 CSS책이다. 그동안 안 본 건 아니지만 내돈으로 구매는 안 했으니까…

결론적으로는 돈 값 한다.

기초를 다시 다지기에도 좋고, 급할 때 펼쳐보는 쿡북 용도로도 좋다.

CSS3에 대해서도 나와 있지만, 그게 주는 아니다.

CSS3만 필요하면 다른 책을 사는게 나을지도. 내용이 부실하다는 게 아니라 삐까뻔쩍한 CSS3로 채워져 있지는 않다는 얘기다.

그리고 CSS 초보(CSS가 뭔지 알고, 글자 색 바꿀 수 있는 정도)가 보기도 충분히 좋다.

책이 얇은데도 색인도 풍부하다. 값도 일단 2만원 아래니까 괜찮은 편.
