군 복무 중 읽은 기술 서적 정리

ISBN:

2011-03-02

크게 혼자서 보면서 배우는 튜토리얼 계와 아무 때나 펼쳐서 볼 수 있는 레퍼런스. 두가지로 분류.

  1. 성공과 실패를 결정하는 1%의 네트워크 원리 2nd edtion -1%시리즈 답게 간략하고 필요한 부분만 담겨 있다. 재판은 그림이 좀 더 많아지고 두꺼워져서 좋은 듯. +가벼운 레퍼런스&튜토리얼
  2. 성공과 실패를 결정하는 1%의 프로그래밍 원리 -오랜만에 다시 읽으니 안 보이던 부분이 보인다. +가벼운 레퍼런스&튜토리얼
  3. 성공과 실패를 결정하는 1%의 컴퓨터 원리 -후임이 샀길래 살짝 봤는데 괜찮은 듯, 사도 좋을 것 같다. +튜토리얼&가벼운 레퍼런스
  4. Beginning oracle programming -DB쓸 일이 많아져서 샀는데, 의외로 많이 안 읽게 되었다. 하지만 없기엔 좀 허전하고... 본격적으로 DB공부를 하려면 좀 더 책이 있어야 하고, 여튼 계륵같은 느낌. +레퍼런스
  5. 유쾌한 자바 퍼즐러 -자바 공부를 하는 김에 봤는데, 예제를 따라 만들지를 않고 한 번 보기만 했다. 다시 보면서 예제를 해 볼 예정. +튜토리얼
  6. Head First OOP -OOP 개념도 좋고, 프로젝트 실제 진행방법에 대한 것이 조금 나와 있어서 괜찮은 것 같다. +튜토리얼&가벼운 레퍼런스
  7. Head First JSP&Servlet -역시 기본은 커맨드라인. 기초 다지기에 부족하지 않다. +튜토리얼&가벼운 레퍼런스
  8. Head First Java -이하동문 +튜토리얼
  9. Head First Design Pattern -헤드 퍼스트는 쉬워서 좋다. 토비의 스프링3와 함께 읽으니 이해도 up. GoF책은 좀 이따 읽어봐야지. +튜토리얼&레퍼런스
  10. DOM Script -DOM에 대한 설명과 적합한 개발방법이 나와있다. 빌려서 읽어도 괜찮았을텐데. +튜토리얼
  11. C언어로 배우는 알고리즘 입문 -양으로 압도한다. 아주 맘에 들었음. 하지만 아직 많이 진행은 못 했다. +튜토리얼&레퍼런스
  12. 숏코딩 -이거 자체로 뭔가 도움이 된다기 보다는, 재밌다. 며칠쯤 진지하게 해도 될 만한 물건. 번역 포인트&반값행사로 구한 물건. +튜토리얼
  13. 하이버네이트 - Harnessing Hibernate -책이 그리 좋지는 않다. 디자인 패턴과 스프링을 읽고 나니까 이해가 되더라. 하이버네이트를 제대로 하려면 다른 책을 구해야겠다. +튜토리얼
  14. 토비의 스프링3 -최근 본 기술서적 중 최고. 스프링에 대한 것 뿐만 아니라 나같은 초보는 보는 것만으로도 능력이 올라가는 기분이 드는 놀라운 척이다. +튜토리얼
  15. SICP -공개된 영문판 PDF의 제본. 역시 어렵다... 아직 제대로 보지도 못했음. +튜토리얼
  16. Introduction to Algorithm -이것도 공개된 영문판 PDF의 제본. 1과 정도를 음성강의 들으면서 진행. +튜토리얼&레퍼런스
  17. Art of Programming -GG +벽돌...ORL
  18. Common LISP -공개된 영문판 PDF 제본. 4장까지 봤던가. 이건 내용도 그럭저럭 따라갈 만 하다. 아니 정확하게 말하자면 쉬울 정도인데, 이것만 가지고는 뭘 못 하겠다. +튜토리얼
  19. 테스트 주도 개발 : 고품질 쾌속개발을 위한 TDD 실천법과 도구 -공개된 PDF만 읽었음. 전체 책은 일단 여기 나온 것을 체화한 다음에... 방향성 자체는 좋은 것 같다. +튜토리얼
  20. DO it! HTML5 + CSS3 -몇 개 따라해 봤다. 개념에 대한 설명보다는 실제로 따라할 수 있는 예제중심. +튜토리얼
  21. 웹디자인 2.0 고급 CSS -아주 맘에 들었다. 디자인에 대한 이야기가 많으면서도 중요한 태그개념이나 CSS의 기술적 설명도 되어 있다. 풀컬러라는 점도 포인트 +튜토리얼
  22. 스타일로 말해요 -부제가 css아는 웹디자이너 되기인데, 프로그래머보다는 웹디자이너에게 설명하는 책. 그래서 다른 사람에게 CSS와 HTML을 어떻게 설명할지를 알게 되었다. +튜토리얼
  23. 리팩토링 -리팩토링에 대한 내용. 일단은 1장까지 밖에... +튜토리얼&레퍼런스
  24. 레거시 코드 활용 -옛날 코드 수정에 필요해 보여서 빌렸는데 마음에 여유가 없고 능력이 없으니 눈에 들어오질 않더라. +모르겠음

우와… 이렇게 보니 꽤 많이 읽었다… 힘내서 공부해야지. 자잘하게 더 읽은 것도 있는 것 같긴 하지만 제목도 생각 안 나는 건 쓰기가 뭣해서 패스.
