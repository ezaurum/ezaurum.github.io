intelliJ에서 gradle 프로젝트 import 시 JAVA_HOME is different 에러가 날때

2013년 2월 17일 글

윈도우 환경에서, intelliJ로 gradle 빌드 파일을 import하려고 하니 JAVA_HOME is different라는 에러가 난다. 메세지를 보니 다 똑같은데, intelliJ가 expect라고 하는 건 디렉토리가 다 소문자, 실제로 있는 건 대문자가 섞여 있다. 보통 JDK는 C:Program FilesJava 아래에 깔리게 되는데, 그냥 c:jdk로 옮겨주고, 시스템 설정에서 JAVA_HOME도 바꿔줬다. 그걸로 해결.
