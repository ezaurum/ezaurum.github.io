redis benchmark 사용법

2013-05-03

redis 실제 사용할 때 성능 체크를 해 보는 간단한 방법 $ ./redis-benchmark -n 30 -r 32 -d 1024 -c 1000

-n 반복 횟수 -r 키 길이(바이트) -d 데이터 길이(바이트) -c 동접 클라이언트 갯수

코어2 듀오, 램 2기가 리눅스 민트에서 실험해 본 결과 대충 1666 request/s 고, 17ms안에 모든 응답이 돌아왔다.
