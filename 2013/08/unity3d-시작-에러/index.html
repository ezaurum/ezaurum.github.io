unity3d 시작 에러

2013년 8월 7일 글

참고
윈도우 7에서 unity3d를 실행하다가
Automatic import for ‘Assets/Standard Assets/Terrain Assets/Terrain Textures/Cliff (Layered Rock).psd’ was disabled because the asset importer crashed on it last time.
You can use ‘Assets -> Reimport’ to enable automatic importing again.
처럼 psd 파일 불러오는 에러가 로그에 찍히면서 사용이 중지되면, dx11 모드로 강제로 실행시키면 해결될 수 있다.
실행시 -force-d3d11 옵션을 주고 실행하면 dx11모드로 실행된다.
문제가 일어난 환경은 i5, Intel HD4600, 윈7

더블 클릭해서 열 때도 dx11모드로 실행하게 하려면 레지스트리에서 다음 키를 찾아서 옵션을 추가함
HKEY_CLASSES_ROOTcom.unity3d.kharmashellOpencommand
