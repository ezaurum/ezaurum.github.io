Sourcetree 에서 access right 에러

2013-04-23

windows용 sourcetree는 개인키를 ppk파일로 지정해 줘야 한다. 그러니 git이 잘 돌아가고 있더라도 그대로는 저장소에 접근도 안 된다.

그러니 tool 메뉴에서 Create or import SSH keys를 선택하면 putty 키 생성기가 뜨는데, 거기서 Conversions 메뉴의 Import key를 선택한다. git이 사용하는 개인키를 선택해서 불러오고, save private keyy를 이용해서 ppk파일을 저장해준다.

다시 tool 메뉴에서 Launch SSH Agent를 클릭하면 ppk 파일을 지정하게 되고 그러면 문제는 모두 해결.
