Unity3D 3.x 대에서 Visual Studio 연동

2013년 4월 30일 글

Edit -> Preferences -> External Script Editor 에서 Browser를 해서 Visual Studio 실행파일을 선택.
이후에 Assets->Sync Mono … 를 하면 Visual Studio가 실행된다.
