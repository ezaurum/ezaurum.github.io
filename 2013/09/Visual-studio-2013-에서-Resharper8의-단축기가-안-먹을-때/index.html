Visual studio 2013 에서 Resharper8의 단축기가 안 먹을 때

2013년 9월 24일 글

딴 건 모르겠고, 일단 제일 많이 쓰는 Alt+Enter가 안 되서 한참 삽질했다.
검색해서 나온 새로 설정 뭐 이런 거 다 해도 안 되는 경우, 도구-옵션-환경-키보드로 간다.

가서 Alt로 검색하면 ReSharper_AltEnter가 있는데, 얘의 바로가기가 XAML UI던가로 되어 있었다. 새 바로 가기를 만드는데, 전역이나 텍스트 편집기를 이용해서 만들어준다. 만들고서 알트 엔터를 누르면 ReSharper단축키랑 딴 거랑 겹친다면서 에러 메세지가 뜨는데, 앞으로 ReSharper 단축키를 쓰겠다고 해 주고, 확인 누르면 됨.
