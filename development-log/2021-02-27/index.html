캐릭터 스테이터스 설정

2021-02-27

  1. 게임 상태 머신 추가 기본적으로 title -> main 으로 가도록 FSM을 추가했다. 이후에 상태 자체를 클래스로 빼 둘 예정

  2. 글로벌 이벤트 버스 추가 mitt 를 써서 글로벌 이벤트 버스를 사용하기로 결정. 메인 메뉴를 클릭하면 글로벌 이벤트가 발생된다

  3. 메뉴 항목의 데이터 구조 정의 각 메뉴 항목마다 데이터 구조를 정의함

  4. 기본 캐릭터 스테이터스 정의 기본 캐릭터 능력치들을 결정함. 이미 전에 결정된 건데, 클래스 만들고 정리함. 다중지능 이론에서 지능을 설정
