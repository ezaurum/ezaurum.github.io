IP network 주소

2010년 8월 3일 글

0### ####.xxxx xxxx.xxxx xxxx.xxxx xxxx A class(0-127) 네트워크 2^7 -2개, 각 네트워크마다 호스트 2^24-2개 10## ####.#### ####.xxxx xxxx.xxxx xxxx B class(128-191) 네트워크 2^14-2개, 각 네트워크마다 호스트 2^16-2개 110# ####.#### ####.#### ####.xxxx xxxx C class(192-223) 네트워크 2^21-2개, 각 네트워크마다 호스트 2^8-2개

각 위치마다 빠지는 두 개는 네트워크부(#로 표시된 것)와 호스트부(x로 표시된 것)0과 1로 채운 2가지. 네트워크부를 모두 0으로 채운 것은 이 네트워크 그 자체를 의미한다고 한다. RFC 791참조 네트워크부를 1로 채운 것은 브로드 캐스트 주소로 쓰인다. RFC 922 참조 127.0.0.1은 보통 localhost(this machine, 지금 사용하고 있는 바로 그 기계)를 의미한다.
