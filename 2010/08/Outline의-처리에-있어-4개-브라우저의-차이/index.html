Outline의 처리에 있어 4개 브라우저의 차이

2010-08-16

Chrome - outline을 element와 같이 그린다.(다음 엘리먼트에 가려진다.) outline이 많이 두꺼우면 모서리에 대각선이 보인다.

IE, opera - outline을 나중에 그린다.(다음 엘리먼트에 가려지지 않는다.) 대각선 없다.

FF - 내용이 없는 경우, outline을 나중에 그리고, 내용이 있는 경우, outline을 먼저 그린다. img가 block 이 아니므로 width, height안 먹는다.

<!DOCTYPE html> <html> <head> <title></title> <style> img{ outline:15px solid green; margin:0px; border:20px solid gray; width:150px; height:150px;

}

.a1 { border:5px solid red; } .a2 { outline:15px solid yellow; margin:5px; } </style> </head> <body> <img src=“aa”/><img src=“aa”/> </body> </html>
