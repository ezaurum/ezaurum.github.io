  1. 블루투스 설정

블투 키보드를 쓰거나 하기 위해서 블루투스를 설정 bluez bluez-utils 을 설치

sudo pacman -S bluez bluez-utils

깔고 나면 블루투스를 기본으로 켜지고 계속 연결이 가능한 상태로 해야 한다. 기본값은 안 켜지게 되어 있다. /etc/bluetooth/main.conf 파일을 수정한다

/etc/bluetooth/main.conf

[Policy]
AutoEnable=true

[General]
DiscoverableTimeout = 0
Discoverable=true
결국 블로그 다시 만들다.
