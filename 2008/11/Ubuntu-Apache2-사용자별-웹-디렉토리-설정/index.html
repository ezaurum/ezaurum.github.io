Ubuntu Apache2 사용자별 웹 디렉토리 설정

2008-11-29

http://leeted.egloos.com/1489000 위 링크 참고 했음.

cd /etc/apache2/mods-available sudo cp userdir.conf userdir.load /etc/apache2/mods-enabled sudo /etc/init.d/apache2 restart
