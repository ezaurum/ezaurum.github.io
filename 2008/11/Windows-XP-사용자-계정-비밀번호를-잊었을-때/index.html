Windows XP 사용자 계정 비밀번호를 잊었을 때

2008년 11월 21일 글

  1. 관리자 -Administrator 계정의 비번을 알 경우

    관리자 계정 로그인-제어판-사용자 계정-비번을 잊은 계정 선택-비밀번호 변경 관리자 계정이 보통 때 뜨지 않는 경우는, 부팅 시, F8을 눌러서 안전모드로 들어간다.

  2. 관리자 계정 비번을 모를 경우

    F8을 눌러서 안전모드 명령 프롬프트 사용 을 선택해서, net user 필요한아이디 *ENTER를 입력. 그럼 비번 재설정 가능.

  3. 둘 다 여의치 않을 경우

    안전모드든, hiren's CD를 이용하든 윈도우즈 폴더의 system32config 폴더 안에 있는 SAM파일을 지우고 재부팅 - 이 방법은 위험하다고 함.
