2014년 정리

2015년 1월 5일 글

읽은 책 - 기록에 남은 것이 46권. 실제로 조금 더 많겠지만 60을 넘기진 않을 것으로 추정. 만화책이랑 라노벨을 더하면 또 확 올라갈테지만… 대부분(40권 가량)이 미야베 미유키 여사의 책이다. 운동 - 수영 1주일 정도 갔나? 최고로 운동 안 한 한 해라고 해도 될 듯. 건강 - 상태가 매우 나쁘다. 표준체중에서 +20kg인 상태. 잔병 치레도 많았고, 체력 회복도 잘 안 되는 수준. 일 - C#/.Net 플랫폼에 좀 익숙해졌다는 느낌이다. 윈도우 서버 세팅도 좀 해 보고… 자잘하게 늘었지만, 이건 결국 시작점에 다시 온 상태. 연봉이라는 측면에서 보면 좀 늘고, 여기저기 성과를 인정받았다고 할 만하지만.. 여전히 맘에드는 수준이 아니다. 잊고 있었는데, 게임 하나를 중국/대만에 출시 해 봤다. 여러 모로 부끄러운 일도 많고, 힘든 기억도 많았다. 처음 정리를 할 때 아예 올해의 일이라는 것도 떠오르지 않을 정도.

성과를 정리해야겠다.

C# TCP/IP 모바일 서버 개발/출시 C# UDP 모바일 서버 개발 (중) C#/.NET/IIS 기반 모바일 대상 서버 개발 (중)

새로 배운 기술/라이브러리 C#, Dapper, nInject, Entity Framework(이건 아주 살짝), IIS, MVC5, Web API 2
