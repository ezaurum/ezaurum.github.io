bitbucket으로 정적 페이지 호스팅하기

2015-04-04

github에서 쉽게 사용할 수 있는 기능(참고 페이지)인데, bitbucket에서도 쓸 수 있다. 호스팅만 할 건데 따로 뭐 서비스 신청하기 뭣하고 해서… 일단 공식 설명서가 있는데 필요한 부분만 발췌해서 간단히 한다.

  1. 일단 Bitbucket에 사용자이름.bitbucket.org 라는 이름으로 리포지토리를 만든다. 이 규칙을 꼭 지켜줘야 한다.
  2. 만든 페이지의 remote 저장소를 bitbucket으로 연결해준다. git remote add origin git@bitbucket:유저이름/유저이름.bitbucket.org.git
  3. 푸시하고 유저이름.bitbucket.org 으로 가서 확인

Bitbucket에서는 커스텀 도메인을 쓸 수 없다. 그냥 github를 쓰자.
