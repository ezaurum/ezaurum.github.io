게임 마케팅 용어

2019-02-05

사용자

  • ARPDAU 일간 활성 사용자 평균 수입, 일간 수입 / 일간 활성 사용자, 서버비 계산할 때 쓰면 되려나
  • ARPU 사용자당 평균 수입, 총수입/총 유저수, 광고비 집행할 때 고려
  • ARPPU 과금 사용자당 평균 수입, 광고비 집행할 때 고려, 낮은 가격의 한 번만 살 수 있는 상품 판촉할 때 고려
  • DAU 일 평균 사용자, 하루 얼마나 오는지
  • MAU 월간 평균 사용자, 한 달에 얼마나 오는지
  • LTV사용자가 수입을 얼마나 가져오나 하는 것
  • F2P게임 하는 건 공짜, 부분유료화 모델

광고

  • CAC 사용자를 획득하는 데 드는 비용, 광고비 및 기타등등, 이게 ARPU 보다 낮으면 무조건 이득
  • CPC 클릭당 비용, 광고를 클릭했을 때 내는 광고 비용
  • CPD 다운로드당 비용, 사용자가 다운로드 했을 때 광고 비용, 게임 다운만 받아도 200원씩 주는 그런 거
  • CPI 설치당 지불하는 광고 비용, 실제 설치했다는 증명이 된다
  • IAA 앱 내 광고
  • IAP 앱 내 구매
