여러 Github 계정 SSH로 접근

2018-08-15

Github 계정이 두 개 이상인 경우, ssh 로 접근하기 위해서는 좀 다른 세팅이 필요하다. 참고링크

1.다른 이름으로 키를 하나 만든다

ssh-keygen -t rsa -b 4096 -C “your_email@example.com”

이러면 파일 이름을 물어볼텐데, 그걸 적당히 다른 이름으로 지정해 준다.

id_rsa_personal

뭐 이런 식으로

2.만든 키를 Github 계정에 등록한다.

3.Git 이 ssh 키를 인식하게 한다

~/.ssh/config

Git 은 이 파일을 가지고 ssh 키를 인식한다.

Host other.github.com
HostName github.com
PreferredAuthentications publickey
IdentityFile ~/.ssh/id_rsa_personal

여기서 other.github.com 이 포인트. 원하는 이름으로 도메인을 지정한다.

4.git 저장소의 remote 를 변경한다.
