AJAX 요청이 간헐적으로 실패하는 문제

2018-09-19

문제 상황 - Ajax 요청이 간헐적으로 잘못된 응답이뜨는데, Axios에서는 에러 메세지가 뜨지 않았다.

문제 원인 - 브라우저에서 If-Modified-Since 를 헤더에 넣어서 보냈고, echo에서는 304를 리턴해 줬다. ajax요청과 html 요청 주소가 같아서 브라우저는 캐시된 html을 로드했고, json 파싱이 되지 않았다.

해결 - HTTP헤더에 If-Modified-Since를 빈 값으로 넣어줬다.
