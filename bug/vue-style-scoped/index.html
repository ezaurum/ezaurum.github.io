Vue에서 외부 모듈의 스타일을 적용했는데 적용되지 않을 때

2018년 8월 31일 버그일기

문제 상황

Vue 프로그래밍 중 외부 모듈을 사용했는데, 해당 모듈의 기본 css를 덮어씌우려고 불러오는 vue 페이지의 style을 변경했다.
클래스 이름을 분명히 지정했고, !important도 먹히지 않았음

문제 원인

알고 보니 style 태그에 scoped가 지정되어 있어서 자동으로 한정자가 붙어버린다. 그러니 단순히 클래스만 지정해서는 해당 모듈에 반영되지 않았다.

재발 방지를 위해

  • 외부 모듈의 경우는 style태그를 따로 하나 더 만들어서 처리한다.
  • CSS를 해당 외부 모듈을 감싸는 부모 태그를 포함해서 선언 한다.
