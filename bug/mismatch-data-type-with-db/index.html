DB에서 값이 255인 컬럼을 읽지 못함

2018-05-15

문제 상황 - byte.MaxValue는 255인데, DB에 255로 적힌 값을 못 받아오고 [OverflowException: 산술 연산으로 인해 오버플로가 발생했습니다.] 가 뜬다.

원인 - DB에는 Int16으로 저장되고, 255면 음수로 저장된다. 음수는 byte형으로 변환할 때 에러가 남.

해결 - Int32로 변경

재발 방지를 위해 - 변수 최대값 범위를 체크, int16이면 127까지만 써야 한다
